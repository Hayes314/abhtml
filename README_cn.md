這是一個從 Python/Pygame 遷移到 **HTML5 + Matter.js** 的完整憤怒的小鳥遊戲，經歷了多輪迭代優化，最終形成一個功能豐富、體驗流暢、跨平台兼容的作品。以下按類別完整介紹所有特色。

## 🎮 一、核心玩法

### 1. 彈弓發射系統
- **拖拽瞄準**：按住彈弓上的小鳥向後拉，調整角度與力度
- **實時軌跡預測**：拖拽時顯示白色虛線拋物線，精確預測飛行路徑（與物理引擎完全同步）
- **力度條**：綠→黃→紅漸變，直觀顯示發射力度
- **最大拉伸限制**：防止拉出邊界，保持遊戲平衡

### 2. 物理引擎（Matter.js）
- **固定時間步長**：60Hz 物理更新，任何刷新率下手感一致
- **高精度求解器**：位置迭代 12 次、速度迭代 10 次，堆疊穩定不抖動
- **圓角碰撞體**：減少方塊卡角問題
- **睡眠機制**：靜止物體自動休眠，大幅降低 CPU 佔用
- **自動喚醒**：方塊被移除時強制喚醒上層，防止浮空

### 3. 傷害系統
- **基於動量**：`衝量 = 相對速度 × 等效質量`，而非單純速度
- **閾值過濾**：低於 6 的衝量忽略，防止自然堆疊自碎
- **材質差異化**：木頭、冰塊、石頭各有不同 HP / 密度 / 摩擦 / 彈性

## 🐦 二、8 種特色小鳥

| 小鳥 | 能力 | 特殊機制 |
|------|------|---------|
| 🔴 **紅鳥** | 無特殊能力 | 標準血量，適合精準射擊 |
| 🟡 **黃鳥** | 衝刺加速 | **可無限使用** + **不受 0.5 秒自動結算限制** |
| ⚫ **黑鳥** | 大範圍爆炸 | **額外存活 2 秒**，可繼續飛行 |
| 🔵 **藍鳥** | 三向分裂 | 扇面覆蓋，每隻繼承 1.15× 速度 |
| ⚪ **白鳥** | 空投蛋炸彈 | **每隻最多 5 次** + 小範圍爆炸（90px）|
| 🟢 **綠鳥** | 回旋鏢 | 瞬間反向飛行，打擊背後目標 |
| 🟠 **橙鳥** | 膨脹重擊 | 質量 ×2.8 持續 1 秒 |
| 🟣 **紫鳥** | 持續電磁場 | **1.5 秒持續脈衝** + **額外存活 2 秒** |

### 特殊設計亮點

**黃鳥**：
- 每次點擊疊加 12px/step 速度（上限 40）
- 可連續點擊穿透多堵牆
- **自動結算豁免**：靜止也不會被強制結束回合

**黑鳥 / 紫鳥延壽機制**：
- 回合本該結束時，額外獲得 **2 秒**活躍時間
- 期間可繼續飛行、可以被撞擊
- 紫鳥可在延壽期內**再次觸發 EMP**
- 延壽光環視覺化（黃/紫脈衝圈）

**白鳥限制**：
- 每隻鳥固定 5 顆蛋額度
- 同時最多 4 顆蛋存活（物理安全）
- UI 實時顯示 `投蛋 X/5`

**紫鳥增強**：
- EMP 半徑 220 → **260px**
- 持續時間 1.0 → **1.5 秒**
- 每 0.25 秒脈衝一次，共 **6 次傷害**
- 累計最高 900 傷害（原版 9 倍）

## 🏗️ 三、智能關卡生成

### 1. 可復現隨機（種子系統）
- **Mulberry32 算法**：同種子 + 同關卡 = 同布局
- **5 位 Base36 種子**：如 `ABC12`，可分享、可重玩
- **種子歷史**：localStorage 保存最近 8 個種子
- **一鍵複製**：點擊 📋 按鈕複製到剪貼板
- **瀏覽器語言推測**：自動匹配系統語言

### 2. 4 種結構模板
- **Tower（塔）**：單柱多層堆疊
- **Pyramid（金字塔）**：底寬頂窄
- **Fortress（堡壘）**：拱門 + 內部藏豬
- **Twin（雙子塔）**：兩塔 + 中間連橋

### 3. 難度曲線
- **結構數量**：2 → 3 → 4（隨關卡遞增）
- **材質傾向**：木頭 → 混合 → 石頭為主
- **小鳥種類**：紅 → 紅黃黑 → 全部 8 種
- **小鳥數量**：按豬數動態計算

### 4. 物理穩定性保障
- **預生成穩定性模擬**：獨立引擎跑 50 步，檢查結構是否崩塌
- **最多重試 8 次**：每次種子 +9973（質數偏移）
- **兜底機制**：都不穩定則返回「最優」版本
- **水平避讓**：防止結構重疊生成

### 5. 防穿模
- **邊界裁剪**：所有物體限制在 `[WALL_LEFT+30, WALL_RIGHT-30]`
- **初始穩定性測試**：不合規的直接跳過
- **三重視覺保護**：左右隱形牆 + 天花板 + 底部地面

| 超寬屏 21:9 | 上下留黑邊，不變形 |

### 5. 觸控與滑鼠雙支持

## 🎮 九、遊戲狀態管理

### 1. 三大狀態
```
aiming（瞄準）→ flying（飛行）→ won / lost（結算）
```

### 2. 自動結算機制（多重保障）
- **0.5 秒靜止自動結束**：除黃鳥外所有小鳥
- **寬鬆倒計時**：鳥消失 1.5 秒 + 微動也倒計時
- **硬超時**：8 秒強制結算（含延壽）
- **跳過按鈕**：鳥消失 30 幀後可手動跳過
- **空格鍵**：隨時跳過

### 3. 防止卡死設計
- **出界移除**：小鳥離開場地立即清理
- **引用同步**：`birdBody = null` 三處同步
- **回合清空**：`endTurn()` 清除所有 bird + egg
- **狀態無條件切回**：`endTurn()` 一定回 `aiming`

### 4. 黃鳥特殊豁免
- **不受 0.5 秒自動結算限制**
- 即使完全靜止也可繼續瞄準
- 讓玩家有「慢慢磨」的選擇
